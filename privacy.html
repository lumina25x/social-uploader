개인정보처리방침

social-uploader · 최종 수정일 2026-09-28

1. 개요

social-uploader(이하 "본 도구")는 운영자가 본인 소유의 채널에 본인이 제작한 영상을 업로드하기 위해 만든 개인용 도구입니다. 제3자에게 배포하거나 서비스로 제공하지 않으며, 운영자 본인 외의 사용자 데이터를 수집하지 않습니다.

2. 수집하는 정보

본 도구는 이용자로부터 어떠한 개인정보도 수집하지 않습니다. Google 계정 인증 과정에서 발급되는 액세스 토큰과 갱신 토큰만 운영자 본인의 로컬 PC에 저장됩니다.

  • 저장 위치: 운영자 로컬 PC의 파일 시스템
  • 외부 서버로 전송하지 않으며, 제3자와 공유하지 않습니다

3. 사용하는 Google API 권한

  • https://www.googleapis.com/auth/youtube.upload
    운영자 본인 YouTube 채널에 영상을 업로드하는 데만 사용합니다.
  • https://www.googleapis.com/auth/youtube.force-ssl
    업로드한 본인 영상에 첫 댓글을 작성하는 데만 사용합니다.

위 권한으로 접근한 데이터는 업로드·댓글 작성 목적 외에 사용하지 않으며, 광고·분석·머신러닝 학습 등 어떤 2차 목적으로도 이용하지 않습니다.

4. Google 사용자 데이터 정책 준수

본 도구의 Google 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함하여 해당 정책을 준수합니다.

5. 데이터 보관 및 삭제

토큰은 운영자가 인증을 해제하거나 파일을 삭제하면 즉시 폐기됩니다. Google 계정 설정의 "타사 앱 및 서비스"에서 언제든 접근 권한을 철회할 수 있습니다.
